# Dream Unity — Crystal Nexus

Dream Unity is a browser-native crystalline three-world simulation deployed through GitHub Pages.

The current homepage is a procedural **Crystal Nexus** interpretation of the supplied Dream Unity artwork:

- a central violet sovereign crystal;
- a translucent celestial sphere and orbital floor;
- faceted Dream Machine, Dream Maker and Dream World portals;
- blue, emerald and violet living orbital conductors;
- attached glass identity plates;
- restrained whole-form mouse, touch and precision-trackpad orbit;
- strictly decaying inertia with no autonomous or accelerating rotation;
- the uploaded **Dream Maker Eye** score with real-time Web Audio response.

The portal game contract remains unchanged:

| World | Games |
|---|---|
| Dream Machine | Fighter Jet · Model Forge · Oracle Gates |
| Dream Maker | Vector Vow · Impulse Run · Become |
| Dream World | Gravity Foundry · Lattice Lock · Genesis Bloom |

## Verification

```bash
npm ci
npm run test:all
```

The browser suite verifies the reference-driven composition, responsive portal plates, music asset, whole-form interaction, non-accelerating inertia, mobile layout, voice-free homepage and all nine games. GitHub Actions then exercises the same tests against the deployed Pages site.
